# Data folder

The source workbook is not committed to this repository package because it contains customer names, email addresses, phone numbers, and other potentially identifying fields.

Before adding data to a public GitHub repository:
1. Confirm you have permission to publish it.
2. Remove or anonymise personal information.
3. Keep only fields needed for the analysis.
4. Prefer a small, synthetic sample for demonstrations.
5. Never commit credentials, private exports, or customer contact details.

The analysis findings in the repository are summarised from the workbook, and should be reconciled against an approved dataset before reuse.
